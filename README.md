# QRly – QR Code Generator

QRly is a simple and professional QR Code Generator built using Python and Flask. It allows users to enter any text or URL, generate a QR code instantly, and download it as a PNG image.

## Features

- Generate QR codes from text or URLs
- Custom filename for generated QR codes
- Download QR codes as PNG images
- Clean and professional user interface
- Responsive design
- Python Flask backend
- Easy to run locally

## Technologies Used

- Python
- Flask
- HTML
- CSS
- QRCode Python Library
